# 証券管理ツール

保有株（日本株・米国株・投信）の資産状況の把握と、銘柄ごとの買い増しルールに基づく
「買い時（買い増しサイン）」の管理を行うツールです。

- 要件: [REQUIREMENTS.md](./REQUIREMENTS.md)
- 詳細設計: [DESIGN.md](./DESIGN.md)

## 現在のステータス（MVP・初版）

まず動かして確認できることを優先した初版です。

- **ログインなし**（確認を簡単にするため。将来 Google ログインを追加予定）
- **保存先 = ブラウザの localStorage**（将来 Google スプレッドシートへ移行予定）
- **株価 = Yahoo 経由で取得（15〜20分遅延）** または手入力。米株のほぼリアルタイム化（Finnhub）は今後
- **通知（LINE/メール）は未実装**。今はアプリ内の「サイン一覧」で買い時を確認

### 実装済みの機能
- 銘柄の登録（市場: 米国株 / 日本株 / 投信、カテゴリ割当）
- 取引の手入力（買い=数量加算＆平均取得単価更新 / 売り=数量のみ減算・単価不変）
- 証券会社（SBI/楽天/Webull/moomoo）× 口座種別（特定/NISA/一般）、端株（小数）対応
- 価格の自動取得（/api/price 経由）＋手入力フォールバック、USD/JPY 円換算
- 買い増し判定（初回=基準高値−40% / 買い増し=前回購入価格−20%、5年高値基準。ルール変更可）
- **「買い増しまであと何%」表示**、サイン一覧
- カテゴリ別 金額マスタ（王道80k/主力60k/準主力50k/防御40k/投機25k/お遊び15k/対象外0、米株は÷100ドル）
- 市場タブ分離（米国株/日本株/投信）、ダッシュボード（円換算・市場別内訳）
- データのエクスポート/インポート(JSON)

## 動かし方

### A. Cloudflare Pages として動かす（推奨・価格自動取得が有効）
価格取得 `/api/price`（Yahoo中継）を使うには Pages Functions を動かす必要があります。

```bash
npx wrangler pages dev .
```

表示された `http://localhost:8788` をブラウザで開きます。

### B. 静的に開くだけ（価格は手入力）
`index.html` を直接ブラウザで開く、または簡易サーバで配信:

```bash
npx serve .
```

この場合 `/api/price` は使えないため、各銘柄の「価格入力」から現在値・5年高値を手入力すると
買い増し判定まで確認できます。

### デプロイ（Cloudflare Pages）
このリポジトリを Cloudflare Pages に接続すれば、`/functions` が自動でAPIになります。
（ビルド不要・出力ディレクトリはルート）

## 使い方の流れ
1. 「米国株」または「日本株」タブ →「＋ 銘柄を追加」でティッカー（例: `AAPL` / `7203`）とカテゴリを登録
2. ヘッダの「価格更新」で現在値・5年高値・為替を取得（取れない場合は各行「価格入力」で手入力）
3. 「取引」から買い/売りを記録 → 保有数量・平均取得単価に反映
4. 「サイン」タブで買い増し到達銘柄と推奨額を確認
